The Three Verdicts

Judge what agents did, not what they said

Rook's three-way verdict separates proven behavior from unverifiable claims — and that distinction is the product.

PASS
Evidence holds
The agent's claim is backed by tool call logs, file system state, or API responses. Trust it.
FAIL
Evidence contradicts
The agent said it did something. The evidence says otherwise. Catch this before it ships.
UNABLE TO VERIFY
No evidence found
The claim can't be confirmed or denied. Excluded from pass rate. This is the assurance gap.
